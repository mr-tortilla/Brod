## [0.2.0] - 2026-10-29

- «Поделиться» профилем (ссылка на подписку или vless:// ссылки, QR-код, JSON sing-box)
  и отдельным подключением (vless:// ссылка, QR-код, JSON).
- Расширенные настройки по вкладкам: порт локального прокси, доступ к прокси из локальной сети,
  обход локальной сети, обновление подписки перед подключением, адрес проверки задержки;
  стек, MTU и строгая маршрутизация TUN, системный прокси в режиме TUN; DNS и IPv6.
  Прежние зашитые значения стали значениями по умолчанию, есть сброс к ним.
- Светлая тема и режим «Как в системе», который следит за темой ОС на лету.
- Локальный прокси по умолчанию на порту 2080 (раньше — случайный свободный; 0 возвращает это поведение).
- Windows: режим TUN без прав администратора больше не падает с непонятной ошибкой — Brod предлагает
  перезапуститься с правами (окно UAC) и сам подключается к выбранному серверу после перезапуска.
- Windows: флаги стран в названиях серверов вместо буквенных кодов (встроенный шрифт Twemoji Country Flags).
- Лог в файл `brod.log` в папке настроек и кнопка «Открыть папку с логами» (Настройки → Прочее).
- Dev-сборку можно запускать рядом с установленным Brod.

## [0.1.0] - 2026-10-28

Первая версия.

- Профили из подписки, vless:// ссылок и JSON-конфигов xray / sing-box.
- Реальная задержка до каждого сервера (URL-тест), закрепление серверов.
- Подключение по клику, режимы «Прокси» и TUN.
- Исключения по доменам, зонам, IP и подсетям; настраиваемые DNS.
- Статус подключения: трафик, задержка, внешний IP и страна.
- Значок в трее с цветом состояния, работа в фоне.
