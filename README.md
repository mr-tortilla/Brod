# Brod

Это не про бутерброд, и не отсылка на Иосифа Бродского (хотя было бы не плохо). 
Брод - место, где реку переходят вброд. 
Десктопный клиент для VLESS под Linux и Windows на ядре [sing-box](https://github.com/SagerNet/sing-box).

## Что умеет

- Профили из подписки (ссылка от провайдера), из `vless://` ссылок или из JSON-конфига xray / sing-box.
- Реальная задержка до каждого сервера, сортировка по ней и закрепление любимых серверов вверху списка.
- Подключение одним кликом по серверу, клик по другому — переподключение.
- Два режима:
  - **Прокси** — системный прокси для браузеров и программ, которые его поддерживают. Права не нужны.
  - **TUN** — через туннель идёт весь трафик системы. Нужны права администратора.
- Исключения: отдельные сайты, IP и подсети открываются напрямую, без туннеля.
- Статус подключения: скорость, объём трафика, задержка, внешний IP и страна.
- Значок в трее: серый — не подключено, зелёный — подключено, красный — связь пропала.
  Закрытие окна сворачивает Brod в трей, соединение продолжает работать.
- «Поделиться» профилем или отдельным сервером: ссылка, QR-код для телефона, JSON.
- Тёмная, светлая и системная тема.

## Установка

Скачайте файл для своей системы со страницы [Releases](../../releases/latest).

### Windows

Запустите `brod-*-windows-setup.exe`. Если не хотите устанавливать — есть portable-версия
`brod-*-windows-portable.zip`: распакуйте и запустите `brod.exe`.

Windows может показать окно «Система Windows защитила ваш компьютер»: у Brod пока нет цифровой подписи.
Нажмите «Подробнее» → «Выполнить в любом случае». Подлинность файла можно сверить с `SHA256SUMS.txt` из релиза:

```powershell
Get-FileHash .\brod-*-windows-setup.exe
```

### Linux

| Дистрибутив                         | Файл                         | Команда                                      |
|-------------------------------------|------------------------------|----------------------------------------------|
| Ubuntu 22.04+, Debian 12+, Mint 21+ | `brod_*_amd64.deb`           | `sudo apt install ./brod_*_amd64.deb`        |
| Fedora                              | `brod-*.x86_64.rpm`          | `sudo dnf install ./brod-*.x86_64.rpm`       |
| openSUSE                            | `brod-*.x86_64.rpm`          | `sudo zypper install ./brod-*.x86_64.rpm`    |
| Arch, Manjaro, EndeavourOS          | `brod-*-x86_64.pkg.tar.zst`  | `sudo pacman -U ./brod-*-x86_64.pkg.tar.zst` |

Brod появится в меню приложений. Права для режима TUN пакет выдаёт сам.

Значок в трее в GNOME требует расширения AppIndicator: в Ubuntu оно уже есть,
в Fedora — `sudo dnf install gnome-shell-extension-appindicator`.

### Обновление

Установите новую версию поверх старой тем же способом — профили и настройки сохранятся.
После установки перезапустите Brod: трей → «Выход», затем запустите снова.

## Как пользоваться

1. **Добавьте профиль**: «+ Добавить» → вставьте ссылку на подписку от провайдера
   (или `vless://` ссылки, или JSON-конфиг на вкладке JSON).
2. **Подключитесь**: кликните по серверу в списке. Цифры справа — задержка через сервер, меньше — лучше.
3. **Выберите режим** внизу слева: «Прокси» для браузера, TUN — чтобы через туннель шло всё.
4. **Исключения** — «Настройки» → «Исключения». Кнопка «+ Российские зоны» добавляет `ru`, `рф` и другие:
   российские сайты будут открываться напрямую, с вашим обычным IP.

Правый клик по профилю — обновить подписку, поделиться или удалить его.
Кнопки на строке сервера (видны при наведении) — поделиться сервером и закрепить его вверху списка.

### Режим TUN

- **Windows**: нужны права администратора. Если Brod запущен без них, при подключении появится кнопка
  «Перезапустить с правами администратора» — после перезапуска Brod сам подключится к выбранному серверу.
- **Linux**: при установке из пакета всё уже настроено.

Не держите одновременно включёнными два VPN-клиента (например, Brod и Hiddify): они мешают друг другу.

## Если что-то не работает

- **Сайты не открываются в режиме TUN** — в «Настройки» → TUN попробуйте MTU 1500 или 1400,
  или выключите «Строгую маршрутизацию».
- **«Порт занят другой программой»** — смените порт в «Настройки» → «Подключение» или поставьте 0.
- **Исключение не срабатывает** — проверьте, что сайт не перенаправляет на другой домен:
  например, `2ip.ru` теперь открывает `2ip.io`, а это уже не зона `ru`.
- **Лог** — «Настройки» → «Прочее» → «Открыть папку с логами», файл `brod.log`.

Профили, настройки и лог хранятся в `~/.config/brod/` (Linux) и `%AppData%\brod\` (Windows).
